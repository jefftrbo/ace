IBM App Connect Enterprise (ACE) + IBM Bob proof-of-concept for UPMC.
Demonstrates what Bob can do for ACE integration development that
GitHub Copilot cannot — specifically, writing and explaining ESQL
transformation logic for HL7 v2 patient data processing.

## What This Demo Shows

A working ACE message flow that mirrors a real UPMC MDM pipeline:

```
HTTP POST (raw HL7 ADT^A01)
        │
        ▼
ESQL Compute Node  ← Bob wrote this; Copilot cannot
        │  • Parses MSH / PID / PV1 / IN1 / DG1 segments
        │  • Extracts MRN, demographics, insurance, ICD-10 diagnosis
        │  • Validates required fields (missing MRN → 422 error)
        │  • Transforms to JSON Golden Record Candidate
        ▼
HTTP Reply
        ├── Valid record   → 200 + JSON Golden Record Candidate
        └── Missing MRN   → 422 + structured error payload
```

The ESQL Compute Node is the centrepiece. It contains the same
HL7 → Golden Record field mapping logic that UPMC's MDM team
depends on to create canonical patient records — written entirely
by Bob, documented line by line, and validated against real
ADT^A01 messages from the hl7-patient-matching project.

## ESQL Field Mapping

The ESQL mirrors the Python parser in the `hl7-patient-matching` project.
Every field offset is documented in the source.

| HL7 Segment | Fields Extracted | Golden Record Target |
|---|---|---|
| `MSH` | Field 3 (sending app), 6 (datetime), 9 (control ID) | `source` block |
| `PID` | Field 3 (MRN), 5 (name), 7 (DOB), 8 (gender), 11 (address), 13 (phone), 19 (SSN) | `mrn`, `name`, `birthDate`, `gender`, `address`, `phone`, `ssn` |
| `PV1` | Field 2 (patient class), 3 (location), 7 (attending), 14 (admission type), 44 (admit datetime) | `encounter` block |
| `IN1` | Field 4 (payer), 8 (group number), 12 (effective date), 15 (plan type), 36 (subscriber ID) | `insurance` block |
| `DG1` | Field 3 (ICD-10 code + description), 5 (onset datetime) | `diagnosis` block |

## ACE Toolkit Setup (Required for Flow Deployment)

The `.msgflow` file must be compiled by the ACE Toolkit before
deployment. The runtime container does not include the Toolkit compiler.

**Toolkit version:** ACE 13.0.8.0 Evaluation Edition (macOS)
**Download:** https://www.ibm.com/docs/en/app-connect/13.0.x?topic=gsace-download-app-connect-enterprise-evaluation-edition-get-started

### Import and Build Steps

1. Launch the ACE Toolkit
2. **File → New → Application** — name it `upmc-hl7-golden-record`
3. Copy `esql/HL7ToGoldenRecord.esql` into the application
4. **New → Message Flow** — name it `HL7GoldenRecordFlow`
5. Wire the flow: **HTTP Input → Compute (HL7ToGoldenRecord) → HTTP Reply**
   - HTTP Input URL: `/hl7/golden-record`, Parse method: `BLOB`
   - Compute node ESQL module: `HL7ToGoldenRecord`
6. **Right-click application → New BAR file** → build
7. Deploy via:

```bash
curl -X POST http://localhost:7600/apiv2/deploy \
  -H "Content-Type: application/octet-stream" \
  --data-binary @upmc-hl7-golden-record.bar
```
